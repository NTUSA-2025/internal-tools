# AGENTS.md instructions

- Do not run Playwright, `npm run dev`, `firebase deploy`, Cloudflare deploy, or production data operations unless explicitly asked.
- Commit small completed edits with conventional commit messages.
- When using `npm install`, `pnpm install`, `pnpm add`, or other commands that require internet access, request elevated permissions.
- Prefer `pnpm nx ...` for Nx tasks such as build, lint, test, and typecheck.
